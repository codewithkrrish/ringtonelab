Fades are shown as shaded zones on the waveform and applied when you export. The preview plays the raw selection; the exported file carries the fades.

4. Export

Load audio to see the estimated export size.

Download

Export is WAV (16-bit PCM) because a real MP3 encoder cannot run in the browser without a large encoder library, and this page ships none. WAV works as a ringtone on Android and most players; iPhones need the file converted to .m4r, which this page does not do — see the limitations below.

How it works

  1. Add a song — drop it, pick it, paste it, or try the demo tone.
  2. Drag a region on the waveform, or use the 30s ringtone preset.
  3. Preview it on loop, set fade in and fade out.
  4. Export a WAV ringtone named after your song. Set it as your ringtone from your phone's settings.

Honest limitations

  • Export is WAV only, for the reason above. It is uncompressed, so a 30-second WAV is roughly 5 MB at CD quality — larger than the same clip as MP3.
  • Whether a file decodes at all depends on your browser's codecs, not on this page. MP3 and WAV work almost everywhere; OGG and FLAC fail in Safari, and DRM-protected files never decode.
  • Very long files are held fully in memory while decoding and exporting. A full-length album in one go can be slow or fail on a low-memory device — trim long sources first.
  • iPhones do not accept WAV files as ringtones directly. You need a converter to .m4r and a sync step through a computer; this page cannot do that step for you.
  • Only use audio you own or have the right to cut. This page does not check rights, and it never uploads your files anywhere.
